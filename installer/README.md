# 灰Desk离线安装包

当前本地测试版本为 `2.2.0-test.20261027.21`，提供中文、当前用户离线安装包，支持安装/覆盖升级、桌面与开始菜单快捷方式及卸载入口。程序变更和验收范围见下方各版本记录。

默认安装到 `%LOCALAPPDATA%\Programs\GrayDesk`，可选择目录。只支持 x64 Windows 10 19041及以上。无需下载运行时或识别模型。安装/卸载前需退出灰Desk，安装器不会强行结束远程连接软件。

安装和升级保留 `%APPDATA%\GrayDeskV2` 的设置。卸载只删除本包自带的文件和入口，不递归清空安装目录，不删除设置或用户添加的文件。正常交互安装结束可勾选启动，静默安装不会自动启动。

## 构建

从 [NSIS官方发布页](https://nsis.sourceforge.io/Download) 下载3.13便携ZIP，解压到 `installer/tools/nsis-3.13`。下载地址为 `https://downloads.sourceforge.net/project/nsis/NSIS%203/3.13/nsis-3.13.zip`，本次ZIP SHA256为 `BA63DFFC4410EE89193E1CB5A41989991BD77C61068DA17E3156D136B7B0B3D8`。

在PowerShell中执行 `installer\Build.ps1`。脚本先核对原程序EXE SHA256，再生成逐文件卸载列表和安装包，输出SHA256及构建记录到 `installer/obj`。编译工具和中间产物不进入源码仓库。

静默安装参数：`/S`，可附加 `/D=完整安装路径`（必须是最后一个参数，路径不加引号）。卸载器支持 `/S`。若灰Desk正在运行，返回10；不支持的Windows返回11。
